# 📄 Резюме

**Конструктор резюме с живым превью.**

### ▶️ [Открыть](https://mysik-portfolio.vercel.app/resume-builder/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- Три шаблона и выбор цвета
- Опыт, образование, навыки и языки
- Предпросмотр листа A4 в реальном времени
- Сохранение в PDF через печать, автосохранение

## Стек

JavaScript, CSS @media print. Один файл `index.html`, без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/resume-builder.git
cd resume-builder
python3 -m http.server 8000
```
